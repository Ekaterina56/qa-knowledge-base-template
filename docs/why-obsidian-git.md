# Чому Obsidian + Git, а не Notion

Рішення ухвалено в листопаді 2026 року. Порівнювали Notion і Git-репозиторій.

## Notion
Зручні бази з фільтрами й добрий пошук, але безкоштовний план не підходить для такої бази:
- ліміт **5 000 блоків** на робочий простір з однією людиною (1 000, якщо учасників двоє й більше);
- лічильник блоків рахує все створене з моменту реєстрації, **видалення не звільняє** блоки;
- записи через API і MCP (тобто робота агента) **теж витрачають** ліміт;
- файли до 5 МБ, усього 512 МБ, історія сторінок — 7 днів;
- API — близько 3 запитів на секунду.

Одна нотатка — це 20–40 блоків, один тест-кейс — 15–25. Ліміт закінчується за тижні. Платний тариф знімає обмеження на блоки, але не на швидкість API.

Джерела (на момент рішення): довідка Notion «Understanding block usage», сторінка тарифів, документація API «Workspace block limits» і «Request limits».

## Git + Obsidian
- Безкоштовно й без лімітів на обсяг тексту; закриті репозиторії безкоштовні і в GitLab, і в GitHub.
- Повна історія кожної правки.
- Агенту швидко: пошук по всіх файлах одразу, без лімітів запитів.
- Людині зручно через Obsidian: пошук по тексту й полях, посилання й зворотні посилання, зведені таблиці через Dataview.
- Синхронізація — плагін Obsidian Git, вручну з Git працювати не треба.

Мінус: на комп'ютері лежить робоча копія. Але це текст: тисячі документів займають кілька мегабайтів. Відео й великі файли зберігаються в хмарі, у базі — посилання.
