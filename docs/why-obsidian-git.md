# Почему Obsidian + Git, а не Notion

Решение принято в ноябре 2026 года. Сравнивались Notion и Git-репозиторий.

## Notion
Удобные базы с фильтрами и хороший поиск, но бесплатный план не подходит для такой базы:
- лимит **5 000 блоков** на рабочее пространство из одного человека (1 000, если участников двое и больше);
- счётчик блоков считает всё созданное с момента регистрации, **удаление не освобождает** блоки;
- записи через API и MCP (то есть работа агента) **тоже расходуют** лимит;
- файлы до 5 МБ, всего 512 МБ, история страниц — 7 дней;
- API — около 3 запросов в секунду.

Одна заметка — это 20–40 блоков, один тест-кейс — 15–25. Лимит заканчивается за недели. Платный тариф снимает ограничение по блокам, но не по скорости API.

Источники (на момент решения): справка Notion «Understanding block usage», страница тарифов, документация API «Workspace block limits» и «Request limits».

## Git + Obsidian
- Бесплатно и без лимитов по объёму текста; закрытые репозитории бесплатны и в GitLab, и в GitHub.
- Полная история каждой правки.
- Агенту быстро: поиск по всем файлам сразу, без лимитов запросов.
- Человеку удобно через Obsidian: поиск по тексту и полям, ссылки и обратные ссылки, сводные таблицы через Dataview.
- Синхронизация — плагин Obsidian Git, вручную с Git работать не нужно.

Минус: на компьютере лежит рабочая копия. Но это текст: тысячи документов занимают несколько мегабайт. Видео и большие файлы хранятся в облаке, в базе — ссылки.
