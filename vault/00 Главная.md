# Главная

Таблицы ниже собираются автоматически плагином **Dataview**. Без него вместо таблиц будет виден код.

Быстрый переход: `Ctrl+O`. Поиск по всей базе: `Ctrl+Shift+F`. Подробнее — [[Как искать]]. Все вопросы с историей — [[Журнал вопросов]].

## Задачи в работе
```dataview
TABLE WITHOUT ID file.link AS "Задача", title AS "Название", platform AS "Платформа", status AS "Статус", dev AS "dev", stage AS "stage", prod AS "prod", updated AS "Обновлено"
FROM "01 Задачи"
WHERE status != "закрыта"
SORT updated DESC
```

## Открытые вопросы
```dataview
TABLE WITHOUT ID file.link AS "Вопрос", task AS "Задача", status AS "Статус", to AS "Кому", asked_date AS "Задан"
FROM "03 Вопросы"
WHERE status != "закрыт" AND status != "отвечен"
SORT created ASC
```

## Вопросы с ответом, которые ещё не применены
```dataview
TABLE WITHOUT ID file.link AS "Вопрос", task AS "Задача", answered_by AS "Ответил", answered_date AS "Дата"
FROM "03 Вопросы"
WHERE status = "отвечен"
SORT answered_date DESC
```

## Требования, которые ещё не согласованы
```dataview
TABLE WITHOUT ID file.link AS "Требование", task AS "Задача", area AS "Раздел", status AS "Статус"
FROM "02 Требования"
WHERE status = "черновик" OR status = "на анализе" OR status = "есть вопросы"
SORT task ASC
```

## Тест-кейсы, которые надо обновить
```dataview
TABLE WITHOUT ID file.link AS "Кейс", area AS "Раздел", task AS "Задача", updated AS "Обновлено"
FROM "05 Тест-кейсы"
WHERE status = "требует обновления"
SORT updated ASC
```

## Последние упавшие прогоны
```dataview
TABLE WITHOUT ID file.link AS "Кейс", area AS "Раздел", last_run AS "Прогон", last_result AS "Результат"
FROM "05 Тест-кейсы"
WHERE last_result = "FAIL"
SORT last_run DESC
```

## Изменено за последние 7 дней
```dataview
TABLE WITHOUT ID file.link AS "Документ", type AS "Тип", file.mtime AS "Изменён"
FROM "01 Задачи" OR "02 Требования" OR "03 Вопросы" OR "04 Решения" OR "05 Тест-кейсы" OR "06 Продукт"
WHERE file.mtime >= date(today) - dur(7 days)
SORT file.mtime DESC
LIMIT 50
```

## Счётчики
```dataview
TABLE WITHOUT ID type AS "Тип", length(rows) AS "Всего"
FROM "01 Задачи" OR "02 Требования" OR "03 Вопросы" OR "04 Решения" OR "05 Тест-кейсы" OR "06 Продукт"
GROUP BY type
```

## По платформам
```dataview
TABLE WITHOUT ID platform AS "Платформа", length(filter(rows, (r) => r.type = "требование")) AS "Требований", length(filter(rows, (r) => r.type = "тест-кейс")) AS "Кейсов", length(filter(rows, (r) => r.type = "вопрос" AND r.status != "закрыт")) AS "Открытых вопросов"
FROM "02 Требования" OR "03 Вопросы" OR "05 Тест-кейсы"
FLATTEN platform
GROUP BY platform
```
