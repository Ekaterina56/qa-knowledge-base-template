# Налаштування: Obsidian і Git

Робиться один раз, хвилин 15.

## 1. Закритий репозиторій
1. У GitLab або GitHub створити порожній проєкт, наприклад `kb-<проєкт>`, **Private**.
2. Позначку «Initialize with README» зняти: репозиторій має бути порожнім.
3. Скопіювати адресу репозиторію (HTTPS).

## 2. Підключити репозиторій до папки
У терміналі, по одній команді:

```powershell
cd <<ПАПКА_БАЗИ>>
```

```powershell
git remote add origin <<АДРЕСА_РЕПОЗИТОРІЮ>>
```

```powershell
git push -u origin main
```

Під час першого надсилання відкриється вікно входу. Для GitLab із паролем-токеном: логін — ім'я користувача, пароль — Personal Access Token із правами `read_repository` і `write_repository`. Токен нікому не пересилати, зокрема в чат з агентом.

## 3. Obsidian
1. Завантажити з офіційного сайту obsidian.md і встановити (папку встановлення можна не змінювати).
2. **Відкрити папку як сховище** → вибрати `<<ПАПКА_БАЗИ>>` (саму папку, не заходячи всередину). На запитання про довіру автору — «Довіряти».
3. **Налаштування → Вбудовані плагіни**: увімкнути **Шаблони**. Папку шаблонів уже вказано: `Шаблони`.
4. **Налаштування → Сторонні плагіни** → **Вийти з обмеженого режиму** → **Огляд**. Встановити й увімкнути:
   - **Dataview** (автор blacksmithgu) — таблиці на головній;
   - **Git** (автор Vinzent) — автосинхронізація.
   Якщо «Огляд» не натискається, перезапустити Obsidian.
5. **Налаштування → Git**:
   - **Automatic → Auto commit-and-sync interval (minutes)**: `10`;
   - **Sync → Pull on startup**: увімкнути (перевірити, що увімкнено).
6. Відкрити [[00 Головна]]: замість коду мають бути таблиці або «No results».

## Як це працює далі
- Користувач і агент пишуть в ті самі файли.
- Поки Obsidian відкритий, раз на 10 хвилин зміни йдуть у репозиторій. Під час запуску Obsidian підтягує зміни.
- Якщо ноутбук зламається: встановити Obsidian і Git, виконати `git clone` — і база на місці разом із плагінами.
- Історію будь-якого файлу видно в репозиторії: відкрити файл → **History**.
