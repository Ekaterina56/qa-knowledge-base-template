# Журнал питань

Усі питання бази в одному місці. Кожне питання — окремий файл у папці `03 Питання`. У ньому: що незрозуміло, варіанти, готовий текст для надсилання, відповідь та **Історія** (коли завели, поставили, нагадали, відповіли). Закриті питання не видаляються, тому за журналом видно всю історію.

Статуси: `відкрите` (ще не поставлене) → `поставлене` → `з відповіддю` (відповідь є, але базу за нею ще не виправили) → `закрите`.

## Треба поставити
```dataview
TABLE WITHOUT ID file.link AS "Питання", task AS "Задача", to AS "Кому", created AS "Заведено"
FROM "03 Питання"
WHERE status = "відкрите"
SORT created ASC
```

## Чекаємо на відповідь
```dataview
TABLE WITHOUT ID file.link AS "Питання", task AS "Задача", to AS "Кому", asked_date AS "Поставлено", asked_where AS "Де"
FROM "03 Питання"
WHERE status = "поставлене"
SORT asked_date ASC
```

## Відповідь є, базу ще не виправили
```dataview
TABLE WITHOUT ID file.link AS "Питання", task AS "Задача", answered_by AS "Відповів", answered_date AS "Дата відповіді"
FROM "03 Питання"
WHERE status = "з відповіддю"
SORT answered_date ASC
```

## Закриті
```dataview
TABLE WITHOUT ID file.link AS "Питання", task AS "Задача", answered_by AS "Відповів", answered_date AS "Дата відповіді"
FROM "03 Питання"
WHERE status = "закрите"
SORT answered_date DESC
```

## Усі питання за задачами
```dataview
TABLE WITHOUT ID rows.file.link AS "Питання", rows.status AS "Статуси"
FROM "03 Питання"
GROUP BY task AS "Задача"
SORT key ASC
```

## За адресатами
```dataview
TABLE WITHOUT ID length(rows) AS "Усього", length(filter(rows, (r) => r.status = "відкрите" OR r.status = "поставлене")) AS "Без відповіді"
FROM "03 Питання"
GROUP BY to AS "Кому"
SORT key ASC
```
