# Как искать

## Горячие клавиши
| Клавиши | Что делает |
|---|---|
| `Ctrl+O` | Открыть документ по названию или ID: набрать номер задачи, `REQ-0012`, название экрана |
| `Ctrl+Shift+F` | Поиск по тексту всей базы |
| `Ctrl+клик` по ссылке | Открыть в новой вкладке |
| `Ctrl+P` → «Вставить шаблон» | Вставить шаблон в новый документ |

На панели справа у каждого документа есть **Обратные ссылки** (backlinks). По ним видно, кто ссылается на этот документ, например все кейсы требования REQ-0012.

## Примеры поиска (`Ctrl+Shift+F`)
| Что найти | Что ввести |
|---|---|
| Всё по задаче | `<<ПРИМЕР_ЗАДАЧИ>>` |
| Открытые вопросы | `[status:открыт]` |
| Всё по экрану «Корзина» | `[area:Корзина]` |
| Всё по админке | `[platform:админка]` |
| Кейсы для веба | `path:"05 Тест-кейсы" [platform:веб]` |
| Только тест-кейсы со словом «гость» | `path:"05 Тест-кейсы" гость` |
| Требования по задаче | `path:"02 Требования" [task:<<ПРИМЕР_ЗАДАЧИ>>]` |
| Решения конкретного человека | `path:"04 Решения" Иван` |
| Точная фраза | `"Clear all"` |
| Исключить слово | `скидка -каталог` |

## Теги
`#задача`, `#требование`, `#вопрос`, `#решение`, `#тест-кейс`, `#справка`. Список тегов — на панели «Теги».

## Если не нашлось
Можно спросить агента: «найди в базе всё про …». Он ищет по тем же файлам.
