# Журнал вопросов

Все вопросы базы в одном месте. Каждый вопрос — отдельный файл в папке `03 Вопросы`. В нём: что неясно, варианты, готовый текст для отправки, ответ и **История** (когда завели, задали, напомнили, ответили). Закрытые вопросы не удаляются, поэтому по журналу видно всю историю.

Статусы: `открыт` (ещё не задан) → `задан` → `отвечен` (ответ есть, но базу по нему ещё не поправили) → `закрыт`.

## Нужно задать
```dataview
TABLE WITHOUT ID file.link AS "Вопрос", task AS "Задача", to AS "Кому", created AS "Заведён"
FROM "03 Вопросы"
WHERE status = "открыт"
SORT created ASC
```

## Ждём ответа
```dataview
TABLE WITHOUT ID file.link AS "Вопрос", task AS "Задача", to AS "Кому", asked_date AS "Задан", asked_where AS "Где"
FROM "03 Вопросы"
WHERE status = "задан"
SORT asked_date ASC
```

## Ответ есть, базу ещё не поправили
```dataview
TABLE WITHOUT ID file.link AS "Вопрос", task AS "Задача", answered_by AS "Ответил", answered_date AS "Дата ответа"
FROM "03 Вопросы"
WHERE status = "отвечен"
SORT answered_date ASC
```

## Закрытые
```dataview
TABLE WITHOUT ID file.link AS "Вопрос", task AS "Задача", answered_by AS "Ответил", answered_date AS "Дата ответа"
FROM "03 Вопросы"
WHERE status = "закрыт"
SORT answered_date DESC
```

## Все вопросы по задачам
```dataview
TABLE WITHOUT ID rows.file.link AS "Вопросы", rows.status AS "Статусы"
FROM "03 Вопросы"
GROUP BY task AS "Задача"
SORT key ASC
```

## По адресатам
```dataview
TABLE WITHOUT ID length(rows) AS "Всего", length(filter(rows, (r) => r.status = "открыт" OR r.status = "задан")) AS "Без ответа"
FROM "03 Вопросы"
GROUP BY to AS "Кому"
SORT key ASC
```
