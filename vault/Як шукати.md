# Як шукати

## Гарячі клавіші
| Клавіші | Що робить |
|---|---|
| `Ctrl+O` | Відкрити документ за назвою або ID: набрати номер задачі, `REQ-0012`, назву екрана |
| `Ctrl+Shift+F` | Пошук по тексту всієї бази |
| `Ctrl+клік` по посиланню | Відкрити в новій вкладці |
| `Ctrl+P` → «Вставити шаблон» | Вставити шаблон у новий документ |

На панелі праворуч у кожного документа є **Зворотні посилання** (backlinks). За ними видно, хто посилається на цей документ, наприклад усі кейси вимоги REQ-0012.

## Приклади пошуку (`Ctrl+Shift+F`)
| Що знайти | Що ввести |
|---|---|
| Усе за задачею | `<<ПРИКЛАД_ЗАДАЧІ>>` |
| Відкриті питання | `[status:відкрите]` |
| Усе по екрану «Кошик» | `[area:Кошик]` |
| Усе по адмінці | `[platform:адмінка]` |
| Кейси для вебу | `path:"05 Тест-кейси" [platform:веб]` |
| Лише тест-кейси зі словом «гість» | `path:"05 Тест-кейси" гість` |
| Вимоги за задачею | `path:"02 Вимоги" [task:<<ПРИКЛАД_ЗАДАЧІ>>]` |
| Рішення конкретної людини | `path:"04 Рішення" Іван` |
| Точна фраза | `"Clear all"` |
| Виключити слово | `знижка -каталог` |

## Теги
`#задача`, `#вимога`, `#питання`, `#рішення`, `#тест-кейс`, `#довідка`. Список тегів — на панелі «Теги».

## Якщо не знайшлося
Можна попросити агента: «знайди в базі все про …». Він шукає в тих самих файлах.
