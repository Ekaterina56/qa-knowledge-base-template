# База знань QA: <<ПРОЄКТ>>

База знань QA за проєктом <<ПРОЄКТ>>: задачі, вимоги, питання, рішення, тест-кейси й довідка про продукт.

- Відкривається в **Obsidian** як сховище (vault).
- Зберігається в закритому Git-репозиторії. Плагін **Obsidian Git** сам зберігає й надсилає зміни.
- ШІ-агент працює з тими самими файлами: правила для нього — у [CLAUDE.md](CLAUDE.md).

Починати з [[00 Головна]] (зведення з фільтрами), [[Журнал питань]] і [[Як шукати]]. Початкове налаштування — [[Налаштування]].

## Платформи

Якщо в продукту кілька платформ, у документів є поле `platform` — список, бо одна вимога може стосуватися кількох платформ одразу. Значення змініть під свій продукт:

| Значення | Що це |
|---|---|
| `застосунок` | Мобільний застосунок |
| `веб` | Веб-версія |
| `адмінка` | Адмін-панель |
| `бекенд` | API і сервіси без власного інтерфейсу |

Приклад: `platform: [застосунок, веб]`. Якщо платформа одна, поле можна не заповнювати, а розділ «За платформами» на головній — видалити.

## Папки

| Папка | Що всередині | ID |
|---|---|---|
| `01 Задачі` | Картка задачі: суть, посилання на вимоги, питання, кейси, результати за середовищами | ключ трекера, наприклад `<<ПРИКЛАД_ЗАДАЧІ>>` |
| `02 Вимоги` | Одна вимога = один файл: вихідна цитата, нормалізований текст, критерії приймання, історія змін | `REQ-0001` |
| `03 Питання` | Неясності: кому поставлені, що залежить від відповіді, відповідь, історія подій | `Q-0001` |
| `04 Рішення` | Підтверджені домовленості й погоджені відмінності від ТЗ («так задумано») | `DEC-0001` |
| `05 Тест-кейси` | Кроки, дані, очікуваний результат, варіанти «не за накатаною», історія прогонів | `TC-0001` |
| `06 Продукт` | Довідка «як влаштовано»: екрани, логіка, середовища, словник | за назвою |
| `07 Вхідні` | Вихідний текст задачі, як він надійшов (з трекера, чату, документа), до нормалізації | дата + тема |
| `Шаблони` | Шаблони для кожного типу документа | — |

## Статуси

- **Задача:** `нова` → `в роботі` → `на ретесті` → `закрита` (або `відкладена`)
- **Вимога:** `чернетка` → `на аналізі` → `є питання` → `погоджено` (або `відхилено`, `застаріло`)
- **Питання:** `відкрите` → `поставлене` → `з відповіддю` → `закрите`
- **Тест-кейс:** `актуальний`, `потребує оновлення`, `застарів`

Статус `погоджено` ставить лише людина. У полі `confirmed_by` завжди вказується людина, а не агент.

Відео й великі файли в репозиторій не кладуться (див. `.gitignore`). Вони зберігаються в хмарі, а в документі лишається посилання.
