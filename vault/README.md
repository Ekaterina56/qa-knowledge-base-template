# База знаний QA: <<ПРОЕКТ>>

База знаний QA по проекту <<ПРОЕКТ>>: задачи, требования, вопросы, решения, тест-кейсы и справка по продукту.

- Открывается в **Obsidian** как хранилище (vault).
- Хранится в закрытом Git-репозитории. Плагин **Obsidian Git** сам сохраняет и отправляет изменения.
- ИИ-агент работает с теми же файлами: правила для него — в [CLAUDE.md](CLAUDE.md).

Начинать с [[00 Главная]] (сводка с фильтрами), [[Журнал вопросов]] и [[Как искать]]. Первичная настройка — [[Настройка]].

## Платформы

Если у продукта несколько платформ, у документов есть поле `platform` — список, потому что одно требование может касаться нескольких платформ сразу. Значения поменяйте под свой продукт:

| Значение | Что это |
|---|---|
| `приложение` | Мобильное приложение |
| `веб` | Веб-версия |
| `админка` | Админ-панель |
| `бэкенд` | API и сервисы без своего интерфейса |

Пример: `platform: [приложение, веб]`. Если платформа одна, поле можно не заполнять, а раздел «По платформам» на главной — удалить.

## Папки

| Папка | Что внутри | ID |
|---|---|---|
| `01 Задачи` | Карточка задачи: суть, ссылки на требования, вопросы, кейсы, результаты по средам | ключ трекера, например `<<ПРИМЕР_ЗАДАЧИ>>` |
| `02 Требования` | Одно требование = один файл: исходная цитата, нормализованный текст, критерии приёмки, история изменений | `REQ-0001` |
| `03 Вопросы` | Неясности: кому заданы, что от ответа зависит, ответ, история событий | `Q-0001` |
| `04 Решения` | Подтверждённые договорённости и согласованные отличия от ТЗ («так задумано») | `DEC-0001` |
| `05 Тест-кейсы` | Шаги, данные, ожидаемый результат, варианты «не по накатанной», история прогонов | `TC-0001` |
| `06 Продукт` | Справка «как устроено»: экраны, логика, среды, словарь | по названию |
| `07 Входящие` | Исходный текст задачи как пришёл (из трекера, чата, документа), до нормализации | дата + тема |
| `Шаблоны` | Шаблоны для каждого типа документа | — |

## Статусы

- **Задача:** `новая` → `в работе` → `на ретесте` → `закрыта` (или `отложена`)
- **Требование:** `черновик` → `на анализе` → `есть вопросы` → `согласовано` (или `отклонено`, `устарело`)
- **Вопрос:** `открыт` → `задан` → `отвечен` → `закрыт`
- **Тест-кейс:** `актуален`, `требует обновления`, `устарел`

Статус `согласовано` ставит только человек. В поле `confirmed_by` всегда указывается человек, не агент.

## Медиа

Видео и большие файлы в репозиторий не кладутся (см. `.gitignore`). Они хранятся в облаке, а в документе остаётся ссылка.
