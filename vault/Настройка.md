# Настройка: Obsidian и Git

Делается один раз, минут 15.

## 1. Закрытый репозиторий
1. В GitLab или GitHub создать пустой проект, например `kb-<проект>`, **Private**.
2. Галочку «Initialize with README» снять: репозиторий должен быть пустым.
3. Скопировать адрес репозитория (HTTPS).

## 2. Подключить репозиторий к папке
В терминале, по одной команде:

```powershell
cd <<ПАПКА_БАЗЫ>>
```

```powershell
git remote add origin <<АДРЕС_РЕПОЗИТОРИЯ>>
```

```powershell
git push -u origin main
```

При первой отправке откроется окно входа. Для GitLab с паролем-токеном: логин — имя пользователя, пароль — Personal Access Token с правами `read_repository` и `write_repository`. Токен никуда не пересылать, включая чат с агентом.

## 3. Obsidian
1. Скачать с официального сайта obsidian.md и установить (папку установки можно не менять).
2. **Открыть папку как хранилище** → выбрать `<<ПАПКА_БАЗЫ>>` (саму папку, не заходя внутрь). На вопрос о доверии автору — «Доверять».
3. **Настройки → Встроенные плагины**: включить **Шаблоны**. Папка шаблонов уже указана: `Шаблоны`.
4. **Настройки → Сторонние плагины** → **Выйти из ограниченного режима** → **Обзор**. Установить и включить:
   - **Dataview** (автор blacksmithgu) — таблицы на главной;
   - **Git** (автор Vinzent) — автосинхронизация.
   Если «Обзор» не нажимается, перезапустить Obsidian.
5. **Настройки → Git**:
   - **Automatic → Auto commit-and-sync interval (minutes)**: `10`;
   - **Sync → Pull on startup**: включить (проверить, что включён).
6. Открыть [[00 Главная]]: вместо кода должны быть таблицы или «No results».

## Как это работает дальше
- Пользователь и агент пишут в одни и те же файлы.
- Пока Obsidian открыт, раз в 10 минут изменения уходят в репозиторий. При запуске Obsidian подтягивает изменения.
- Если ноутбук сломается: установить Obsidian и Git, выполнить `git clone`, и база на месте вместе с плагинами.
- Историю любого файла видно в репозитории: открыть файл → **History**.
