# Головна

Таблиці нижче збирає автоматично плагін **Dataview**. Без нього замість таблиць буде видно код.

Швидкий перехід: `Ctrl+O`. Пошук по всій базі: `Ctrl+Shift+F`. Докладніше — [[Як шукати]]. Усі питання з історією — [[Журнал питань]].

## Задачі в роботі
```dataview
TABLE WITHOUT ID file.link AS "Задача", title AS "Назва", platform AS "Платформа", status AS "Статус", dev AS "dev", stage AS "stage", prod AS "prod", updated AS "Оновлено"
FROM "01 Задачі"
WHERE status != "закрита"
SORT updated DESC
```

## Відкриті питання
```dataview
TABLE WITHOUT ID file.link AS "Питання", task AS "Задача", status AS "Статус", to AS "Кому", asked_date AS "Поставлено"
FROM "03 Питання"
WHERE status != "закрите" AND status != "з відповіддю"
SORT created ASC
```

## Питання з відповіддю, яку ще не застосовано
```dataview
TABLE WITHOUT ID file.link AS "Питання", task AS "Задача", answered_by AS "Відповів", answered_date AS "Дата"
FROM "03 Питання"
WHERE status = "з відповіддю"
SORT answered_date DESC
```

## Вимоги, які ще не погоджено
```dataview
TABLE WITHOUT ID file.link AS "Вимога", task AS "Задача", area AS "Розділ", status AS "Статус"
FROM "02 Вимоги"
WHERE status = "чернетка" OR status = "на аналізі" OR status = "є питання"
SORT task ASC
```

## Тест-кейси, які треба оновити
```dataview
TABLE WITHOUT ID file.link AS "Кейс", area AS "Розділ", task AS "Задача", updated AS "Оновлено"
FROM "05 Тест-кейси"
WHERE status = "потребує оновлення"
SORT updated ASC
```

## Останні невдалі прогони
```dataview
TABLE WITHOUT ID file.link AS "Кейс", area AS "Розділ", last_run AS "Прогін", last_result AS "Результат"
FROM "05 Тест-кейси"
WHERE last_result = "FAIL"
SORT last_run DESC
```

## Змінено за останні 7 днів
```dataview
TABLE WITHOUT ID file.link AS "Документ", type AS "Тип", file.mtime AS "Змінено"
FROM "01 Задачі" OR "02 Вимоги" OR "03 Питання" OR "04 Рішення" OR "05 Тест-кейси" OR "06 Продукт"
WHERE file.mtime >= date(today) - dur(7 days)
SORT file.mtime DESC
LIMIT 50
```

## Лічильники
```dataview
TABLE WITHOUT ID type AS "Тип", length(rows) AS "Усього"
FROM "01 Задачі" OR "02 Вимоги" OR "03 Питання" OR "04 Рішення" OR "05 Тест-кейси" OR "06 Продукт"
GROUP BY type
```

## За платформами
<!-- Якщо платформа одна, цей розділ можна видалити. -->
```dataview
TABLE WITHOUT ID platform AS "Платформа", length(filter(rows, (r) => r.type = "вимога")) AS "Вимог", length(filter(rows, (r) => r.type = "тест-кейс")) AS "Кейсів", length(filter(rows, (r) => r.type = "питання" AND r.status != "закрите")) AS "Відкритих питань"
FROM "02 Вимоги" OR "03 Питання" OR "05 Тест-кейси"
FLATTEN platform
GROUP BY platform
```
